# AI Coin Collection Scanner

Browser Beta for creating a structured coin inventory from collection photos.

## Browser Beta

Open `beta/index.html` through GitHub Pages once Pages is enabled for this repository.

The Browser Beta supports photo upload, coin records, public-reference checks, research-priority labels, and Excel/CSV export.

## Important

This Beta assists with inventory and research. It does not guarantee coin identification, authenticity, rarity, or value.

For grouped photos, keep coins in the same positions when turning them over so front and reverse photos can be matched more reliably.

A blank Excel template is included under `docs/AI-Coin-Inventory-Empty-Beta.xlsx`.
