辅助硬币清单 + 公开硬币参考资料

为你的硬币收藏建立清晰的数字清单。

上传照片，在多枚硬币的照片中检测可能的单枚硬币，检查正面和背面的对应关系，用公开参考资料辅助研究，并导出为 Excel 或 CSV。

🔒 照片和清单数据保留在这个浏览器中。
第 1 步

选择硬币照片

0 张原始照片 · 0 个裁剪图

一张照片可以有一枚或多枚硬币。最简单可靠的方法是：拍背面时，让每枚硬币保持在和正面照片相同的位置。支持 JPG/JPEG、PNG 和 WebP。

多枚硬币照片自动检测

选择一张正面照片，也可以选择一张背面照片。系统会尝试找到硬币形状并建立裁剪图。这只是实验性的图像检测，不是确定的硬币识别。请自己检查结果。

还没有运行自动检测。

第 2–3 步

检查并修改清单

0 枚硬币

每枚硬币的正面、背面和边缘照片都可以单独修改。填写能看到的文字或特征，然后使用“检查公开参考资料”。研究优先级有三个等级：值得研究、可能值得研究、普通。

请选择照片、检测硬币或手动建立记录。

这个 Beta 能做什么，不能做什么

Beta 可以建立与照片关联的私人硬币清单，并实验性地检测硬币形状。最后的检查由你完成。它不保证硬币身份、稀有程度、价值、真伪、金属成分或品相等级。
