Guía de fotos

Las fotos claras y numeradas de forma coherente facilitan la creación y revisión del inventario.

1. Fotografía grupos manejables

Coloca las monedas separadas y fotografía desde arriba con luz uniforme.

2. Mantén cada moneda en la misma posición

Al fotografiar el reverso, deja cada moneda en la misma posición.

3. Numera las parejas de fotos

Usa nombres como 01-anverso y 01-reverso.

4. Comprueba las parejas

Comprueba siempre que el anverso y el reverso pertenecen a la misma moneda.

Plantilla Excel vacía

También puedes empezar con la plantilla Excel vacía si prefieres introducir los datos manualmente.

Importante: la Browser Beta no guarda las fotos dentro del archivo Excel. La exportación conserva números de foto, nombres de archivo originales y referencias de imagen para poder localizar las fotos originales. Guarda tú mismo esas fotos junto al Excel. Si quieres que las imágenes estén físicamente dentro de Excel, debes insertarlas manualmente en Excel.

Guarda tu inventario

Guarda el archivo Excel junto con las fotos originales para conservar una referencia clara para futuras comprobaciones e investigaciones.
