Photo guide

Clear, consistently numbered images make it much easier to build and check your coin inventory.

1. Photograph manageable groups

Place coins separately on a plain, contrasting surface. Photograph straight from above in good, even light. Avoid overlap, glare and deep shadows.

2. Keep every coin in the same position

When you turn a group over for the reverse image, keep each coin in exactly the same position.

3. Number image pairs

Use simple matching names, for example 01-front and 01-reverse, followed by 02-front/02-reverse.

4. Check the pairing yourself

Always verify that the front and reverse shown for a coin belong together. Correct the link when necessary.

5. Add useful detail

If a date, mint mark or text is difficult to read, take an extra close-up. An edge image can also help for unusual coins.

You can start with the empty Excel template if you prefer to enter data manually.

Download empty Excel template

Important: the Browser Beta does not place photos inside the Excel file. The export keeps photo numbers, original filenames and image references so you can find the original files again. Keep those original photos yourself. If you want images physically embedded in Excel, you must insert them manually in Excel.

Avoid

Overlapping coins, changing positions between image pairs, strong reflections, motion blur and important details hidden by fingers or holders.

Save your inventory

Save the Excel file together with the original photos. This keeps photo numbers and filenames useful for later checking and research.
